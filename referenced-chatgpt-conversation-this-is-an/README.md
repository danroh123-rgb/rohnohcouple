# 우리에게 온 작은 기적

두 가족에게 링크를 먼저 보내고 영상 통화에서 함께 마지막 공개를 볼 수 있는 한국어 임신·성별 공개 페이지입니다. 정적 파일만 사용하므로 빌드 과정이나 서버 프로그램 설치가 필요 없습니다.

## 미리보기

- `index.html`을 브라우저에서 열면 시댁용 경험이 보입니다.
- 친정용은 사이트 주소 뒤에 `?family=parents`를 붙입니다.
- 기본 설정은 `preview`이며 성별을 표시하지 않습니다. 버튼을 눌러도 “아직 비밀” 상태만 나옵니다.

## NIPT 결과 확인 후 설정

`config.js`를 열어 다음 값을 수정합니다.

```js
window.REVEAL_CONFIG={
  family:'inlaws',                 // 기본 경험: inlaws 또는 parents
  revealMode:'final',              // 결과 확인 후 preview에서 final로 변경
  babySex:'girl',                  // girl, boy, surprise 중 하나
  dueDate:'2026년 5월',             // 선택 사항
  babyName:'',                     // 선택 사항
  ultrasoundImage:'images/first-hello.jpg', // 선택 사항
  coupleNames:'민지와 준호'           // 서명에 표시할 이름(원하는 표현으로 변경)
};
```

성별 선택은 `girl`이면 공주님(핑크), `boy`이면 왕자님(블루), `surprise`이면 성별 명칭 없이 무지개 톤으로 연출됩니다. 친정용 링크에는 임신 공개가 포함되므로, 양가에 각각 보낼 주소를 구분해 주세요.

## 초음파 사진 추가

1. 프로젝트 안에 `images` 폴더를 만듭니다.
2. 공유해도 괜찮은 사진 사본을 `images/first-hello.jpg`로 저장합니다.
3. `config.js`의 `ultrasoundImage`를 `images/first-hello.jpg`로 설정합니다.

공개 링크가 생기면 사진 파일도 주소를 아는 사람에게 공개될 수 있습니다. 의료기관/환자번호 등 불필요한 개인정보가 사진에 찍혀 있는지 확인하고, 원본 대신 잘라낸 사본을 사용하세요.

## 배포하고 링크 보내기

무료 정적 호스팅 서비스(예: Netlify Drop, Cloudflare Pages, GitHub Pages)에 이 폴더의 파일을 올리면 HTTPS 주소가 생깁니다. 서비스가 제공하는 공개 설정 화면에서 게시 범위와 주소를 확인한 다음, 그 주소를 가족에게 전달하세요. 설정에 따라 검색엔진에 노출될 수 있으니 사이트 주소만 아는 사람에게 공유한다고 해서 접근이 제한되지는 않습니다.

1. NIPT 결과가 확인되기 전에는 `revealMode:'preview'`인 상태로 가족 문구와 사진 배치를 확인합니다.
2. 결과를 확인한 뒤 `config.js`에 성별과 선택 정보를 입력하고 `revealMode:'final'`로 바꿉니다.
3. 수정된 폴더를 호스팅 서비스에 다시 게시합니다.
4. 공개 전 양쪽 링크를 각각 열어 문구와 마지막 공개 화면을 점검합니다.
5. 영상 통화 직전에 각 가족에게 해당 링크를 보냅니다. 친정 링크는 임신 공개가 포함됩니다.

이 페이지는 암호로 보호되지 않으며, URL의 `?family=parents`는 가족별 문구를 고르는 용도일 뿐 비밀 보안 기능이 아닙니다. 초음파 사진이나 출산 예정일을 넣는 경우 신뢰하는 가족에게만 링크를 보내고, 공개가 불편하면 해당 정보는 빼세요. 영상 통화 전 테스트할 때는 민감한 사진을 아직 넣지 않은 미리보기 상태를 사용하면 됩니다.

## 화면 흐름

1. 감성적인 인사말과 천천히 내려가는 안내
2. 가족에게 보내는 편지 (친정에서는 여기서 임신 소식 공개)
3. 첫 인사 / 초음파 사진
4. 버튼을 누르는 성별 공개 대기
5. 색상 전환, 큰 타이포그래피와 컨페티 효과
6. 영상 통화에서 만나요 메시지
